# Installation

```bash
npm install
```

# Build

```bash
npm run build
```

# Prévisualisation locale

```bash
npm run preview
```

# Déploiement GitHub Pages

Le projet est configuré pour GitHub Pages avec le chemin de base `/Projet3Dgame/`.
Le déploiement est automatique via GitHub Action au push sur la branche `main`.

Dans les réglages du dépôt, il faut choisir **GitHub Actions** comme source Pages si nécessaire.

# Utilisation

```bash
npm run dev
```
